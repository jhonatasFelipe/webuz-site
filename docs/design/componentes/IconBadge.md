# IconBadge

Ícone dentro de um círculo — o selo de categoria e de passo visto nas telas e no "Como funciona".

Props: `icon`, `tone` (`brand` | `teal` | `sun` | `soft`), `size` (padrão 48), `ring` (anel duplo `brand` usado nos passos do site), `label`.

`brand` para categorias e passos; `teal` para algo concluído; `sun` só para conquista/1º lugar; `soft` dentro de listas.

No site (HTML/CSS): `.wb-ib .wb-ib-brand|teal|sun|soft .wb-ib-ring`.
