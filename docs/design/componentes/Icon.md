# Icon

Ícone herdando a cor do texto (`currentColor`). No site são os ícones do Font Awesome embutidos como SVG (ver [../icones.md](../icones.md)); no Design System, um conjunto provisório de traço com os mesmos nomes.

Props: `name`, `size` (padrão 24), `strokeWidth` (padrão 2), `label` (quando o ícone é a única informação — senão fica oculto para leitores de tela).

Nomes: bus, star, gift, trophy, check, chat, map, phone, crown, coupon, share, pin, bell, user, arrowLeft, arrowRight, apple, play.

**Substituto:** as telas originais usam ícones ilustrados que não foram entregues como arquivo; troque este conjunto pelos originais quando existirem.

No site (HTML/CSS): `svg inline`.
