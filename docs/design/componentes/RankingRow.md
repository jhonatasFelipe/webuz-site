# RankingRow

Linha do ranking com selo de posição, apelido e pontos.

Props: `position`, `name`, `points`, `me` (destaca a linha do usuário com "· você").

Selos: 1º `sun`, 2º `teal`, 3º `brand`, demais `wheel`. Envolva as linhas em `<div class="wb-rank-list">` para o card arredondado.

No site (HTML/CSS): `.wb-rank .wb-rank-list`.
