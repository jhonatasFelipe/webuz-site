# SegmentedTabs

Abas segmentadas para alternar visões dentro de uma tela.

Props: `items` (rótulos), `value` (índice controlado, opcional), `onChange(index)`, `label` (nome acessível do grupo).

Aba ativa em `brand` com `on-brand`. Duas a três abas, rótulos curtos.

No site (HTML/CSS): `.wb-tabs .wb-tab`.
