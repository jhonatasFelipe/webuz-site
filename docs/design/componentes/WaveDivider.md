# WaveDivider

Onda em três camadas (`sun`, `brand` e, na base, `teal`) que separa o hero do resto da página — tirada do esboço do site.

Props: `flip` (inverte para fechar uma seção), `className` — use `s-wave-band` ou `s-wave-band-alt` para a onda continuar o fundo pastel da seção de cima.

Uma ou duas por página, nunca seguidas.

No site (HTML/CSS): `.wb-wave`.
