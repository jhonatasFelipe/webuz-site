# MissionItem

Linha de missão do dia com ícone, título, recompensa e estado.

Props: `title`, `icon`, `points` (opcional, mostrado como "+N pontos"), `done`.

Concluída: check `teal`. Pendente: círculo vazio com borda `line`. Título no imperativo: "Avalie 3 ônibus".

No site (HTML/CSS): `.wb-mission .wb-check`.
